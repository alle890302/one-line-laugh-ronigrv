# The One-Line Laugh

A tiny program that writes one funny line to `/output/entry.txt`:

> My houseplant died of neglect, my sourdough died of attention — turns out I'm not a caretaker, I'm a climate.

Entry for make.fun's [The One-Line Laugh](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f) bounty.

## Run

```sh
python3 main.py
```
